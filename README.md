# Ecommerce Backend API

A RESTful backend API for an ecommerce application built using **Node.js, Express, MongoDB, and Mongoose**.

## Features
- User Registration & Login (JWT Authentication)
- Product Management (Add, View, Update, Delete)
- Cart Management (Add to Cart, View Cart, Remove Item, Clear Cart)
- Protected Routes using Auth Middleware

## Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs

## Project Structure
- controllers – Business logic
- models – Mongoose schemas
- routes – API routes
- middlewares – Authentication middleware
